# Contributing to PX

## Code of Conduct
Governed by CODE_OF_CONDUCT.md. Report unacceptable behavior to founder@priprostudios.site.

## How to contribute
- Bugs: open an issue with title, expected vs actual behavior, steps to reproduce, environment, logs/screenshots.
- Enhancements: open an issue describing the change and why it matters.
- Pull requests: fork/branch from main, make focused changes, add tests, open PR against main, ensure checks pass.

## Style guidelines
Follow existing code style, use conventional-commit style messages, update documentation when changing behavior.
